MUSICAL INSTRUMENT FREQUENCY ANALYZER

ABOUT THE PROJECT

This is a B.Tech Mathematics mini project.

In this project, we model a guitar string using small masses and springs. We use matrices, eigenvalues and eigenvectors to study how the string vibrates.

AIM OF THE PROJECT

The main aim of this project is to find the natural frequencies and vibration modes of a guitar string.

HOW THE PROJECT WORKS

The program takes three inputs from the user.

1. Number of points or masses
2. Mass of each point
3. Spring constant

Using these inputs, the program creates a stiffness matrix and a mass matrix.

Then it calculates the eigenvalues and eigenvectors.

The eigenvalues are used to find the natural frequencies.

The eigenvectors show the shape of vibration of the string.

The program displays the first three vibration modes using graphs.

MATHEMATICS USED

The main mathematics concepts used in this project are

Matrices

INPUT

The user gives the number of masses, mass of each point and spring constant.

OUTPUT

The program gives the first three natural frequencies and shows the first three vibration modes using graphs.

REAL WORLD APPLICATION

Musical instruments produce sound because they vibrate.

A guitar string produces different sounds when it vibrates at different frequencies.

This project uses eigenvalues and eigenvectors to study these vibrations mathematically.

CONCLUSION

This project helps us understand how eigenvalues and eigenvectors can be used in a real world application.

It also shows how mathematics can be connected with musical instruments.
